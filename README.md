# HamDis
Hamming distance-based analysis of methylation dissimilarity

## Updated software

- [`hameth_v2`](hameth_v2/README.md): depth-balanced PAT Hamdist bin selection,
  BAM-to-PAT preparation, and equal-CpG cell-by-cell matrix construction.
- [`hammeth`](hammeth/README.md): original implementation retained for
  reproducibility of earlier analyses.
